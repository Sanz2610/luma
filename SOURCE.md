Each snapshot includes the application, build configuration, dependency lockfile and tests. See its README for Windows build instructions and SOURCE_MANIFEST.json for file SHA-256 values and the development commit used for export. Runtime src/ and electron/ files retain the exact released application source. Earlier snapshots can include additive author/license/resource metadata, explicitly recorded in the manifest.

Work-in-progress history and internal workflow documents remain private. No personal photo libraries, profiles, caches, credentials or validation screenshots are included. Donation QR assets were supplied for public distribution by the project owner.

The release's SHA256SUMS.txt checks binary download integrity. Public source and manifests help review the implementation; they do not by themselves prove a particular executable was built from that source. Reproducible executables and publisher signing are not currently promised.

The original v1.6.0 tag predates source publication and remains unchanged. Use its named source snapshot here, or the source-v1.6.0 tag, to inspect that version's application code.
