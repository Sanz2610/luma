# Luma - Free Windows Media Viewer

Luma is a free, open-source photo and video viewer for Windows 10/11 (x64). Browse local media in a thumbnail grid, switch folders with tabs, and open files in a separate viewer. English interface. Developed by [Sanz2610](https://github.com/Sanz2610).

**Download Luma 1.12.1:** [Windows installer](https://github.com/Sanz2610/luma/releases/download/v1.12.1/Luma-1.12.1-Setup.exe) · [Portable EXE](https://github.com/Sanz2610/luma/releases/download/v1.12.1/Luma-1.12.1-Windows.exe)

- Adjustable thumbnail size, square or 4:5 grids, folder tabs and nested folders.
- Filter by file type, image dimensions or filename keyword.
- Zoom, fullscreen, image metadata and MP4/MOV video playback.
- Select multiple files to copy, move or delete to Windows Recycle Bin. Duplicate names are numbered without overwriting existing files.
- Google Lens search and customizable folder links.

## Supported formats

- Images: JPG/JPEG, PNG, WebP, AVIF and BMP.
- Static previews: GIF, TIFF, HEIC/HEIF, JPEG XL (JXL) and camera RAW, including ARW, DNG, CR2/CR3 and NEF. RAW requires an embedded preview.
- Video: MP4 and MOV. Playback depends on codecs; H.264/AAC is tested. See [codec details and licenses](CODEC_SOURCES.md).

**Install and update:** Setup defaults to Program Files and may request Administrator access. Installed copies update through Settings > Updates. Portable users download a new EXE. Builds are not publisher-signed.

Browsing is local. Google Lens sends a preview only when clicked; update checks use GitHub. Files change only through explicit organize/delete actions.
